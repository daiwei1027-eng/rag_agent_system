## 统一块契约

文字和表格均使用相同的四字段结构：

```json
{
  "block_index": 0,
  "type": "text",
  "text": "用于后续切分的文字",
  "source_html": "<p>供来源复核的 HTML</p>"
}
```

type 为 text 或 table，所有块都保留非空 text 和 source_html。文字块不因为
不是表格就放弃 HTML 来源结构。source_html 是 BeautifulSoup 的序列化结果，
并非原始文件的精确字节切片；溯源还依赖原文 hash、章节锚点和块位置。

block_index 是噪声过滤前的候选块序号，过滤后允许有间隔；它与 section_id 共同
定位块，不是原始 HTML 的字符偏移，也不是未来的 FAISS 向量行号。

章节记录包含 section_id、document_id、section、section_title、起止 anchor、
metadata、blocks 和统计信息。metadata 从输入 manifest 继承公司、ticker、财年、
报告期、表单、accession、来源 URL/文件路径，并绑定 source_sha256。
最终 chunk 仍沿用既有 chunk_id/text/source/metadata 外层契约。

## 表格转换与已知边界

使用物理网格保留单元格位置：

- colspan：文字写入第一列，其余覆盖列保留空位置。
- rowspan：在覆盖的后续行重复该文字及横向占位，不把后面的值挤到错误列。
- 渲染行统一补齐到整表最大列数；处理跨度后省略全空的排版行。
- 单元格内部相邻 span 不强行插入空格，br 保留文字边界。
- 不支持嵌套表格、非正跨度和跨度重叠，明确报错而不是静默压平。

真实保留表格共 74 张，66 张使用 colspan，1 张使用 rowspan，没有嵌套表格。
rowspan 表格位于 Alphabet FY2024 Item 7，含 Less FX Effect、Constant Currency
Revenues 等跨行表头。未自动推断语义表头、币种单位、逻辑列分组或财务计算关系。
物理网格会保留较多排版空列，后续表格 chunk 策略需要考虑长度，不能把行列保持
等同于已完成财务语义理解。
